# 界面与功能同步记录

本次同步保留开源仓库的基础生成流程，更新创作界面并补充本地功能。

## 同步内容

- 更新首页、创作入口、项目列表、项目工作区与分集工具栏的布局和移动端样式，补充创作指南与工具说明页。
- 增加自定义风格与题材库，参考图保存在本机；预设风格从 278 个增至 306 个。原有 278 张模型预览图保留，新增 28 张编辑设计的概念封面，用于表达风格方向。
- 增加二次元创作入口，复用现有项目与图片创作流程。
- 增加主题视频的画面与声音脚本规划、编辑，以及用户选定本地片段后的 FFmpeg 手动拼接。
- 增加上传作品库，支持自有封面、分集视频和字幕的上传、本地浏览与播放。
- 增加本地反馈及附件保存、PWA 安装入口和离线提示页。离线页只提供连接提示，模型生成仍需连接所选供应商。

## 保留范围

剧本优化、分镜优化及现有基础生成逻辑保持原样；未引入自动质检、质量触发的返修或自动多段生成。对原有 278 个风格进行了兼容性核对，原有提示词前缀、负面提示词与风格约束保持不变。

项目记录继续写入 `LOCAL_DATA_DIR/workspace.json`，媒体继续保存在 `LOCAL_DATA_DIR/media`。新增功能沿用本地身份、JSON 文件存储及本机媒体服务，未引入云端趋势服务、远程业务 API、数据库、对象存储、支付或遥测。模型请求仍使用本地用户自己的供应商凭据。

## 本次验证

- `npm ci`、`npm run typecheck`、`npm run lint`、`npm run build` 均通过；lint 保留 1 条既有导航方式警告。
- 同步脚本的 8 项临时仓库隔离测试通过。依赖安装仍报告 8 项既有审计告警，本次未调整依赖。
- 完整测试结果：2106 项通过，16 项跳过，3 项失败。失败涉及章节生成、实体提取及大纲恢复，已在同步前基线复现，为既有问题。
- 既有剧本与分镜生成、优化相关的 34 个受保护文件与同步前一致；278 个既有风格的 4726 项对比全部通过。
- 测试使用操作系统临时数据目录和模拟模型响应；没有调用付费模型，也未将测试媒体或用户数据加入仓库。
